# Бот «Московский Движ» — бесплатный Render

Эта версия рассчитана на **Render Free Web Service**. В отличие от исходной версии, она использует Telegram webhook, внешнюю PostgreSQL-базу и внешний планировщик. Платный Background Worker и постоянный диск не нужны.

## Что делает бот

- Готовит до трёх черновиков в день.
- Отправляет черновики администратору в личные сообщения.
- Публикует в `@moscow_dvizh_rus` только после нажатия «Опубликовать».
- Кнопка «Отклонить» снимает черновик с рассмотрения.
- `/id` показывает Telegram ID, `/now` запускает подготовку вручную, `/status` показывает состояние.

Время: 09:00, 14:00 и 19:00 по Москве.

## Важные ограничения бесплатного Render

Бесплатный Web Service засыпает после периода отсутствия входящих запросов, а локальные файлы могут исчезнуть при перезапуске. Поэтому:
1. Черновики и история сохраняются во внешней бесплатной PostgreSQL-базе Neon.
2. cron-job.org будит сервис за пять минут до каждого запуска и вызывает подготовку в нужное время.
3. После простоя первый запрос может обрабатываться с задержкой. Это бесплатный режим, поэтому абсолютную своевременность гарантировать нельзя.

OpenAI API оплачивается отдельно от подписки ChatGPT. Бесплатный Render не делает запросы OpenAI бесплатными.

## Подготовка

### 1. Neon — бесплатная база данных

1. Откройте https://neon.tech/ и создайте бесплатный проект.
2. В панели проекта найдите **Connect** и скопируйте PostgreSQL connection string.
3. Сохраните строку целиком — она понадобится в Render как `DATABASE_URL`.
4. Не публикуйте её и никому не отправляйте: в ней есть пароль базы данных.

Таблицы бот создаст автоматически при первом запуске.

### 2. Render — бесплатный Web Service

1. Откройте https://dashboard.render.com/.
2. Выберите **New → Blueprint** и подключите GitHub-репозиторий с файлами этой версии.
3. Render прочитает `render.yaml`. Проверьте, что сервис называется `moskovskiy-dvizh-bot`, тип — **Web Service**, план — **Free**.
4. Если Render предлагает платный план или диск, остановитесь: для этой версии они не нужны.
5. Заполните переменные окружения:

| Переменная | Что указать |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather |
| `OPENAI_API_KEY` | Ключ OpenAI API |
| `CHANNEL_ID` | Уже задано: `@moscow_dvizh_rus` |
| `ADMIN_USER_ID` | Ваш числовой Telegram ID |
| `DATABASE_URL` | PostgreSQL connection string из Neon |
| `CRON_SECRET` | Случайная строка из латинских букв и цифр, не менее 32 символов |
| `WEBHOOK_SECRET` | Другая случайная строка из латинских букв и цифр, не менее 32 символов |

Для `CRON_SECRET` и `WEBHOOK_SECRET` можно сгенерировать отдельные случайные значения в менеджере паролей. Не используйте один и тот же секрет для обеих переменных.

6. Создайте сервис и дождитесь статуса **Live**.
7. Скопируйте адрес сервиса Render, например `https://moskovskiy-dvizh-bot.onrender.com`.

### 3. cron-job.org — расписание

Создайте бесплатный аккаунт на https://cron-job.org/.

Так как бесплатный Render засыпает, для каждого времени нужны два задания: одно будит сайт за пять минут, второе запускает черновик.

В cron-job.org установите часовой пояс **UTC** и создайте 6 GET-заданий. В адресах замените `YOUR-SERVICE` на домен Render, а `YOUR_CRON_SECRET` — на значение переменной `CRON_SECRET`.

| Действие | Время UTC | URL |
|---|---:|---|
| Разбудить перед 09:00 МСК | 05:55 | `https://YOUR-SERVICE.onrender.com/wake` |
| Создать черновик | 06:00 | `https://YOUR-SERVICE.onrender.com/cron?key=YOUR_CRON_SECRET` |
| Разбудить перед 14:00 МСК | 10:55 | `https://YOUR-SERVICE.onrender.com/wake` |
| Создать черновик | 11:00 | `https://YOUR-SERVICE.onrender.com/cron?key=YOUR_CRON_SECRET` |
| Разбудить перед 19:00 МСК | 15:55 | `https://YOUR-SERVICE.onrender.com/wake` |
| Создать черновик | 16:00 | `https://YOUR-SERVICE.onrender.com/cron?key=YOUR_CRON_SECRET` |

Для каждого задания выберите повторение **Every day** и метод **GET**. Не публикуйте URL с секретом в открытом доступе.

## Проверка

1. Откройте в браузере `https://YOUR-SERVICE.onrender.com/health` — должен появиться ответ `{"status":"ok"}`.
2. Напишите Telegram-боту `/start`.
3. Напишите `/status`.
4. Напишите `/now`, чтобы проверить создание первого черновика без ожидания расписания.
5. Бот присылает фотографию отдельным сообщением, затем текст черновика с кнопками подтверждения и отдельное сообщение со страницей Wikimedia и лицензией. Проверьте пост, затем нажмите «Опубликовать» или «Отклонить». При публикации в канал фотография и текст также отправляются отдельными сообщениями.

## Права бота в канале

Бот должен быть администратором `@moscow_dvizh_rus` с правом **Публикация сообщений**.

## Безопасность

- Никогда не отправляйте токен Telegram, OpenAI API key, пароль Neon или `CRON_SECRET` в чат.
- Если секрет случайно попал в публичный репозиторий, немедленно замените его.
- Бот раскрывает Google News-ссылки до страницы издателя, пытается извлечь полный текст, а при неудаче использует только описание RSS как ограниченный резерв. Кандидаты с недостаточным текстом пропускаются. Поиск Wikimedia привязан к теме заголовка, а лицензия проверяется по метаданным. Автоматическая проверка всё равно не заменяет ручную проверку: Wikimedia-фото могут быть иллюстративными, а не изображением конкретного события.
